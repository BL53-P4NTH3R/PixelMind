# Week 2: Feature Detection & Matching

## 📌 Project Overview
This project explores classical feature detection and feature matching techniques in computer vision.
The goal is to identify distinctive points in images, describe their local appearance, and match
corresponding features across image pairs. These techniques form the foundation for higher-level
applications such as image alignment, panorama stitching, object recognition, and 3D reconstruction.

---

## 🎯 Objectives
- [x] Implement Harris Corner Detection to identify interest points
- [x] Detect and describe local features using SIFT and ORB
- [x] Match feature descriptors between image pairs
- [x] Visualize keypoints and feature correspondences
- [x] Demonstrate the connection between feature matching and image stitching

---
